# Video Summarization

1. Read [`CLAUDE.md`](../../../CLAUDE.md) completely before processing input. Treat it as the canonical workflow.
2. Follow its workflow in order, including source-specific transcript retrieval, applicable factual and visual reviews, archival download, final editing, verification, and cleanup.
3. Scope every mutation to the requested video. Preserve unrelated `CLAUDE.md`, models, transcripts, summaries, and local media.
4. Remove only the current video's intermediate transcript artifacts, and only after verifying the summary and archive.
5. If required input or access is unavailable, preserve partial work and request the missing input instead of bypassing the workflow.
